# SQL Projects Portfolio

Welcome to my SQL portfolio. This repository contains data analysis projects demonstrating my ability to work with relational databases, transform raw data, write analytical SQL queries, and generate business insights from real-world datasets.

My projects cover the **music, road safety, and restaurant industries** and demonstrate SQL skills including joins, aggregations, Common Table Expressions (CTEs), window functions, ranking, date analysis, segmentation, and data transformation.

## Projects

### 🎵 1. Digital Music Store Analysis

**Objective:** Analyze a digital music store database to understand customer behavior, music preferences, artist performance, and revenue opportunities.

**Key Analysis:**
- Identified senior employees based on job level
- Analyzed invoice distribution across countries
- Identified highest-value invoices
- Determined the best customers based on spending
- Analyzed Rock music listeners
- Identified top-performing Rock artists
- Determined the most popular music genre by country
- Identified top-spending customers by country
- Analyzed customer spending on individual artists

**SQL Skills:**  
Joins, CTEs, window functions, `DENSE_RANK()`, aggregation, subqueries, `GROUP BY`, `ORDER BY`, `COUNT()`, `SUM()`, and `AVG()`

### 🚗 2. UK Road Accident Analysis

**Objective:** Analyze UK road accident data to examine accident severity and understand patterns associated with different vehicle and motorcycle categories.

**Key Analysis:**
- Calculated median accident severity codes by motorcycle type
- Evaluated accident severity and accident counts by vehicle type
- Calculated average severity codes across vehicle categories
- Analyzed motorcycle accident counts and average severity
- Connected accident, vehicle, and vehicle-type datasets

**SQL Skills:**  
Multi-table joins, CTEs, window functions, `ROW_NUMBER()`, median calculations, `COUNT(DISTINCT)`, `AVG()`, `SUM()`, grouping, and filtering

### 🍽️ 3. Zomato Restaurant Data Analysis

**Objective:** Analyze restaurant data to understand geographic distribution, ratings, pricing, customer engagement, service availability, cuisines, and restaurant growth.

**Key Analysis:**
- Analyzed restaurants by city and country
- Examined restaurant openings over time
- Created calendar and financial date attributes
- Segmented restaurants by ratings and pricing
- Calculated table-booking and online-delivery percentages
- Identified highest-rated restaurants by country
- Identified restaurants with the most customer votes
- Ranked restaurants using ratings and votes
- Analyzed restaurant cuisine information

**SQL Skills:**  
Joins, CTEs, window functions, `ROW_NUMBER()`, `DENSE_RANK()`, `CASE` statements, date functions, percentage calculations, string manipulation, ranking, and aggregation
